# WhatsApp Baileys: Deep Anti-Ban Architecture

Библиотека `@whiskeysockets/baileys` позволяет работать с WhatsApp Web API. Чтобы минимизировать риски бана, наша Node.js программа должна выглядеть для серверов Meta в точности как легитимный WhatsApp Web, запущенный в браузере Safari на macOS или Chrome на Windows.

## 1. Конфигурация Сокета (SocketConfig)

При вызове `makeWASocket` необходимо передавать специфические параметры:

### Browser Property
По умолчанию Baileys может передавать дефолтные строки. Их нужно жестко переопределить.
```javascript
browser: ['Mac OS', 'Chrome', '10.15.7'] 
// Или ['Windows', 'Chrome', '120.0.0.0']
```
Это сигнализирует WhatsApp, что сессия привязана к десктопному браузеру, а не к нестандартному устройству.

### Version (Версия протокола)
WhatsApp постоянно обновляет версию Web-клиента. Если использовать устаревшую захардкоженную версию, аккаунт быстро забанят.
- Используйте `fetchLatestBaileysVersion()` при каждом запуске.

### syncFullHistory: false
При привязке устройства WhatsApp пытается синхронизировать историю. Если бот запрашивает полную историю для мультиаккаунтов, это создает огромную нагрузку и выглядит подозрительно.
- **Установить `syncFullHistory: false`**. Нам не нужна история чатов до подключения бота, нас интересуют только новые лиды.

### markOnlineOnConnect: false
- По умолчанию не стоит светить статус "Онлайн" круглосуточно.
- Установите `markOnlineOnConnect: false`.
- Посылайте сигнал присутствия (`sendPresenceUpdate('available')`) только непосредственно перед отправкой сообщения, и `'unavailable'` после.

## 2. Имитация ввода (Typing Indicators)

Не отправляйте сообщения мгновенно.
1. Установите статус `composing` (печатает).
2. Задержка, пропорциональная длине сообщения (например, `text.length * 50ms`).
3. Отправка сообщения.
4. Сброс статуса (или автоматический сброс после отправки).

```javascript
await sock.sendPresenceUpdate('composing', jid);
await delay(text.length * 50); // Эмуляция печати
await sock.sendMessage(jid, { text: text });
```

## 3. Обработка Квитанций (Read Receipts)
Алгоритм Meta следит за тем, читает ли клиент входящие сообщения.
- Если приходит сообщение от лида, бот должен отправить сигнал `read` (`sock.readMessages([key])`), имитируя просмотр чата. Глухие боты, которые только пишут, вычисляются быстро.
