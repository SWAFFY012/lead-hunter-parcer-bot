# AI Prompts & Spintax Architecture

Данный документ содержит золотой стандарт для работы с локальными LLM (такими как Llama 3) и генерации холодных рассылок через Spintax.

---

## 1. Идеальный System Prompt (Для Ollama)

Для получения идеальных результатов от Llama 3 (или Mistral) критически важно использовать жесткий системный промпт на английском языке, чтобы ограничить галлюцинации и заставить модель выдавать чистый текст без "шелухи".

Вставьте этот текст в поле `system_prompt` в разделе **AI Messages**:

```text
You are a highly skilled B2B sales expert and copywriter. Your goal is to write a single, highly converting cold outreach message to a potential client.

CRITICAL CONSTRAINTS - YOU MUST OBEY ALL OF THEM:
1. OUTPUT ONLY THE MESSAGE TEXT. Absolutely NO introductory or concluding phrases (e.g., DO NOT output "Here is your message:" or "Sure, here it is:").
2. DO NOT use ANY Markdown formatting. No asterisks (*), no bold, no italics, no bullet points.
3. DO NOT offer to show or send any pre-made visuals, mockups, prototypes, or concepts. We only propose a discussion or a brief call.
4. STRICT LENGTH LIMIT: The final message MUST NOT exceed 250 characters. Keep it extremely brief, punchy, and respectful of the reader's time.
5. The language of the message must be Russian.
6. The tone must be professional, natural, and conversational. Do not sound like a robot.
```

## 2. Spintax Словарь (Словарь синонимов)

Используйте этот словарь для конструирования поля `message_template`. Вы можете комбинировать блоки, чтобы каждое отправленное сообщение было уникальным и не попадало под спам-фильтры WhatsApp.

### 2.1. Приветствия (10+ вариантов)
От строго формальных до более нейтральных:
`{Здравствуйте|Добрый день|Приветствую|Доброго дня|Привет|Добрый вечер|Доброе утро|Рад приветствовать|Приветствую вас|Доброго времени суток}`

### 2.2. Причина обращения / Крючок
Как экологично объяснить, откуда взят номер:
`{Нашел ваш контакт на OLX|Увидел ваше объявление на OLX|Наткнулся на ваше объявление на OLX|Заметил ваш профиль на OLX|Искал услуги на OLX и увидел вас|Нашел ваше предложение на OLX|Обратил внимание на ваше объявление}`

### 2.3. Оффер (Разработка сайтов под ключ)
Короткие питчи, фокусирующиеся на результате, а не процессе:
`{Мы разрабатываем современные сайты под ключ|Мы создаем удобные сайты для бизнеса|Занимаемся разработкой сайтов под ключ|Можем сделать для вас отличный сайт для генерации заявок|Делаем сайты, которые стабильно приводят клиентов|Разрабатываем конверсионные веб-сайты для бизнеса|Помогаем бизнесу с упаковкой — делаем сайты под ключ}`

### 2.4. Оффер (Telegram-боты)
Питчи с акцентом на автоматизацию и экономию времени:
`{Мы делаем Telegram-ботов для автоматизации процессов|Разрабатываем умных телеграм-ботов для бизнеса|Делаем ботов в Telegram для роста продаж|Создаем Telegram-ботов, которые экономят время сотрудников|Занимаемся внедрением ботов в Telegram для автоматизации рутины|Разрабатываем чат-ботов для автоматического сбора заявок}`

### 2.5. Призыв к действию (CTA - Закрытие на ответ)
Вопросы, которые легко закрывают человека на ответ "Да/Нет":
`{Актуально для вас?|Вам было бы это интересно?|Хотите обсудить детали?|Подсказать по стоимости?|Рассматриваете такие варианты сейчас?|Открыты к предложениям?|Интересно узнать подробности?|Сориентировать вас по ценам?|Подсказать, как это работает?|Есть ли сейчас потребность в этом?}`

### 💡 Пример сборки полного шаблона (message_template):
`{Здравствуйте|Добрый день}, {{name}}! {Увидел ваше объявление на OLX|Нашел ваш контакт на OLX}. {Мы разрабатываем современные сайты под ключ|Занимаемся разработкой сайтов под ключ}. {Актуально для вас?|Подсказать по стоимости?}`

## 3. Правила обработки имен (Sanitization)

Пользователи на OLX часто вводят имена небрежно. Если мы отправим в Ollama шаблон с `Привет, иван стройка 24!`, конверсия упадет до нуля.

**Инструкция для бэкенда (функция очистки перед Spintax/Ollama):**

1. **Удаление мусора:** Регулярным выражением вырезать все цифры и специальные символы (смайлики, тире, скобки). Оставить только кириллицу и латиницу.
   *Пример:* `иван стройка 24` -> `иван стройка`
2. **Выделение первого слова:** Если слов несколько, всегда брать только первое слово (это спасет от "Игорь Сантехник" -> "Игорь").
   *Пример:* `иван стройка` -> `иван`
3. **Капитализация:** Перевести первую букву в верхний регистр, остальные — в нижний.
   *Пример:* `иван` -> `Иван`; `aNNA` -> `Anna`.
4. **Fallback (Заглушка):** Если после очистки строка оказалась пустой (или содержит менее 2 символов), использовать пустую строку для переменной `{{name}}`, а логику Spintax настроить так, чтобы при пустом имени запятая перед ним не ставилась, либо использовать нейтральное слово.

*Код для бэкенда (пример регулярки):*
```javascript
function sanitizeName(rawName) {
  if (!rawName) return '';
  // Убираем всё, кроме букв и пробелов
  let clean = rawName.replace(/[^A-Za-zА-Яа-яЁё\s]/g, '').trim();
  // Берем первое слово
  let firstWord = clean.split(/\s+/)[0];
  if (!firstWord || firstWord.length < 2) return '';
  // Форматируем регистр
  return firstWord.charAt(0).toUpperCase() + firstWord.slice(1).toLowerCase();
}
```
