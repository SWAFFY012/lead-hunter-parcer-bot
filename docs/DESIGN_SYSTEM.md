# LeadHunter UI/UX Design System

## 1. Цветовая палитра
Дизайн выдержан в строгом профессиональном B2B стиле. Упор сделан на чистоту и читабельность.

### Основные цвета (Brand & Surface)
- **Primary Accent:** Indigo `#4F46E5` (hover: `#4338CA`)
- **Background Base:** Light Gray `#F8F9FA` (основной фон приложения)
- **Surface (Cards/Modals):** White `#FFFFFF`
- **Surface Alt:** Gray `#F1F3F5` (для hover состояний и блоков выделения)
- **Borders:** `#E5E7EB` (слабые), `#D1D5DB` (строгие)

### Текст
- **Text Primary:** `#111827` (заголовки, основной текст)
- **Text Secondary:** `#6B7280` (подзаголовки, неактивные элементы)
- **Text Tertiary:** `#9CA3AF` (заглушки, мелкие подписи)

### Семантические цвета (Status & Feedback)
- **Success:** `#059669` (фон: `#D1FAE5`)
- **Error:** `#DC2626` (фон: `#FEE2E2`)
- **Warning:** `#D97706` (фон: `#FEF3C7`)
- **Info:** `#0284C7` (фон: `#E0F2FE`)

## 2. Типографика
- **Font-Family (Основа):** `IBM Plex Sans`, -apple-system, sans-serif
- **Font-Family (Код/Данные):** `IBM Plex Mono`, monospace (используется для ID, телефонов, логов)
- **Размеры:**
  - `text-xs`: 0.75rem (12px) - Бейджи, мелкие логи
  - `text-sm`: 0.8125rem (13px) - Таблицы, формы
  - `text-base`: 0.9375rem (15px) - Основной текст
  - `text-lg`: 1.0625rem (17px) - Подзаголовки модалок
  - `text-xl`: 1.25rem (20px) - Заголовки страниц
  - `text-3xl`: 1.875rem (30px) - Крупные цифры в статистике

## 3. Базовые компоненты

### Кнопки (Buttons)
- `.btn`: Базовый класс (border-radius: 8px, font-weight: 500, transition).
- `.btn-primary`: Фон `#4F46E5`, белый текст. При hover легкий подъем `translateY(-1px)` и тень `0 4px 14px rgba(79,70,229,0.3)`.
- `.btn-secondary`: Белый фон, строгий бордер `#D1D5DB`. При hover фон `#F1F3F5`.
- `.btn-ghost`: Прозрачный фон, серый текст.
- `:disabled`: `opacity: 0.5`, `cursor: not-allowed`, отключены hover-эффекты.

### Карточки (Cards)
- `.card`: Белый фон, бордер `#E5E7EB`, скругление 12px, легкая тень `0 1px 2px rgba(0,0,0,0.05)`.
- `.stat-card`: Используется для вывода цифр статистики.

### Элементы форм (Forms)
- Input/Select/Textarea: скругление 8px, бордер `#D1D5DB`.
- При фокусе: смена бордера на Indigo и свечение `0 0 0 3px rgba(79,70,229,0.1)`.

### Таблицы (Tables)
- Заголовки `<thead>`: фон `#F1F3F5`, текст UPPERCASE `text-xs`, полужирный.
- Строки `<tbody>`: белый фон, разделитель снизу. При hover окрашиваются в `#F1F3F5`.

### Status Badges (Пилл-бейджи)
Круглые плашки с цветным кружком-индикатором слева. Текст UPPERCASE, размер 12px.
- **Новый:** серый фон / серый текст (`#6B7280`)
- **Отправлено:** голубой фон / синий текст (`#0284C7`)
- **Ответил:** фиолетовый фон / фиолетовый текст (`#7C3AED`)
- **Онлайн:** зеленый фон / зеленый текст (`#059669`)

### Toast-уведомления
- Всплывают в правом нижнем углу. Белая карточка с цветным левым бордером (4px) в зависимости от типа (Success, Error, Info). Анимация выезда справа `toastIn`.
