# LeadHunter Frontend Architecture

## 1. Технологический стек
- React 18, Vite, TypeScript
- React Router v6 для навигации
- Socket.io-Client для реалтайм связи
- Vanilla CSS (Design System tokens)

## 2. Глобальный Layout
Приложение использует Sidebar-архитектуру (`App.tsx` / `Sidebar.tsx`).
- `ToastProvider` обертывает все приложение для глобальных всплывающих уведомлений (например, при ответе лида).
- Каждый экран (Page) имеет стандартизированную шапку `.page-header` и прокручиваемое тело `.page-body`.

## 3. Дерево страниц и Управление состоянием (State)

### 1. Dashboard (`/`)
- **Функция:** Главный экран со сводкой.
- **State:** `stats` (общие счетчики лидов/кампаний), `recentLeads` (последние собранные лиды), `logs` (глобальная лента активности системы).
- **Реалтайм:** Слушает `lead:replied`, `parser:lead`, `sender:log`, `account:status`.

### 2. Accounts (`/accounts`)
- **Функция:** Управление WhatsApp сессиями.
- **State:** `accounts` (массив аккаунтов), `qrData` (текущий QR код), `newId` (поле для добавления).
- **Реалтайм:** Слушает `account:status` и `account:qr`.

### 3. Parser (`/parser`)
- **Функция:** Интерфейс настройки и запуска парсера OLX.
- **State:** `form` (url, pages, campaignId), `parserStatus` (запущен/нет, есть ли сессия браузера), `progress` (текущий прогресс сбора в процентах и цифрах), `logs`.
- **Реалтайм:** Слушает весь скоуп `parser:*` эвентов.

### 4. Leads (`/leads`)
- **Функция:** CRM для просмотра лидов и диалогов.
- **State:** `leads` (массив для таблицы), `filters` (поиск, статус), `selected` (выбранный лид для боковой панели), `messages` (история сообщений), `noteText` / `newTag`.
- **Взаимодействие:** Клик по строке таблицы открывает `.side-panel` с детальной карточкой лида (редактирование тегов, статуса, просмотр истории чата).

### 5. AIMessages (`/ai`)
- **Функция:** Шаблонизация и генерация сообщений через Ollama.
- **State:** `prompts` (CRUD шаблонов), `leads` (список лидов со статусом new), `selectedLeadIds`, `batch` (массив результатов генерации), `ollamaStatus`.
- **Взаимодействие:** Выбор промпта -> Выбор лидов -> Генерация -> Ручная проверка в карточках -> Одобрение.

### 6. Sender (`/sender`)
- **Функция:** Массовая рассылка по подготовленным лидам.
- **State:** `campaigns` (селект кампании), `accounts` (селект аккаунтов), `status` (running, stats), `logs`.
- **Реалтайм:** Слушает `sender:*` эвенты (progress bar обновляется онлайн).

### 7. Warmup (`/warmup`)
- **Функция:** Прогрев WhatsApp аккаунтов.
- **State:** `status` (состояние алгоритма, дневной прогресс каждого аккаунта), `logs` (история переписок между своими номерами), `liveLogs` (системные события).
- **Взаимодействие:** Тумблеры включения прогрева для каждого отдельного аккаунта.

### 8. Settings (`/settings`)
- **Функция:** Глобальная конфигурация.
- **State:** `settings` (ключ-значение: тайминги, телефон мониторинга, URL Ollama, ключи).
- **Взаимодействие:** Загрузка при маунте, сохранение единым PUT запросом.
