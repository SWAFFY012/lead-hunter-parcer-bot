# Фаза 7: Оптимизация продаж и удержание лидов (Pipeline & Retention)

На основании вашего запроса, мы откладываем мульти-парсинг и фокусируемся на трех мощнейших механиках для "дожима" лидов и удобства менеджера. 

## 1. 🗂 Kanban-доска (Визуальная воронка)
Табличный вид идеален для массовой рассылки, но для ведения теплых диалогов нужна наглядность.

**Что сделаем:**
- Добавим новую вкладку в боковое меню: `Воронка` (Pipeline).
- Используем легковесную библиотеку (например, `@hello-pangea/dnd`) для Drag-and-Drop интерфейса.
- Создадим колонки под ключевые этапы: `Ответили` ➡️ `В работе (Переговоры)` ➡️ `Сделка` ➡️ `Отказ`.
- При перетягивании карточки лида из колонки в колонку, фронтенд будет автоматически отправлять `PATCH /api/leads/:id` для смены статуса.
- В карточке на доске будет отображаться Имя, Последнее сообщение и таймер (сколько времени лид висит без ответа).

## 2. 🤖 AI-Суфлер в чате (Smart Replies)
Повышаем скорость ответов менеджера, используя уже настроенную локальную модель Qwen 2.5.

**Что сделаем:**
- В интерфейсе чата (карточка лида) рядом с полем ввода добавим кнопку `✨ Сгенерировать ответ`.
- Бэкенд-эндпоинт: `POST /api/leads/:id/generate_reply`.
- Логика: Бэкенд берет последние 4-5 сообщений из переписки, формирует системный промпт (например, "Действуй как вежливый менеджер по продажам, ответь на вопрос клиента коротко и по делу") и отправляет в Ollama.
- Ollama генерирует текст (с `keep_alive: 0` для экономии памяти) и возвращает его.
- Текст подставляется в поле ввода (не отправляется сразу!). Менеджер может его отредактировать и нажать "Отправить".

## 3. ⏰ Система Follow-up (Авто-дожимы)
Не даем лидам остыть, если они проигнорировали первое сообщение.

**Что сделаем:**
- Добавим в таблицу `leads` поле `followup_count` (по умолчанию 0).
- Напишем фоновый Cron-скрипт (или `setInterval` на бэкенде), который раз в час проверяет базу.
- Если лид находится в статусе `sent` (то есть не ответил) более 24 часов, и `followup_count == 0`, система автоматически отправляет мягкое сообщение (например: *"Здравствуйте! Удалось ли посмотреть мое предыдущее сообщение?"*).
- Поле `followup_count` увеличивается до 1. Если ответа нет еще 48 часов, можно отправить финальный дожим.
- Добавим UI-настройку на Дашборд или в Настройки для включения/выключения авто-дожимов.
